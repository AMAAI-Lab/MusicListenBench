# MusicListenBench leaderboard

Compare audio language models on paired listening tests for melody, harmony,
timbre, and rhythm. The leaderboard shows results from rendered audio and real recordings.

[Paper](https://arxiv.org/abs/2611.29375) · [Dataset](https://huggingface.co/datasets/amaai-lab/MusicListenBench) · [Evaluation code](https://github.com/AMAAI-Lab/MusicListenBench/tree/release) · [Submit a result](https://amaai-lab.github.io/MusicListenBench/submit.html)

This Space syncs with the [GitHub leaderboard repository](https://github.com/AMAAI-Lab/MusicListenBench).
